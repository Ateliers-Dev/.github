# Ateliers-Dev

Ateliers-Dev では、Organization 内の技術テーマやプロジェクトに取り組み、組織としての規約・開発方針を定めています。

- [公式サイト ateliers.dev](https://ateliers.dev/)では、Organization として取り決めた規約や開発方針、技術ノート、Ateliers のプロジェクトナレッジを公開しています。
- [公開リポジトリ一覧](https://github.com/orgs/Ateliers-Dev/repositories)から、各プロジェクトのソースコードや README を参照できます。

# Issue Type・共通ラベル運用方針への参照

> 作成日: 2026-11-24
> 更新日: 2026-11-24
> 作成者: Codex

Ateliers-Dev の Issue Type と共通ラベルの運用方針の正本は、[ateliers-website の Development Guidelines](https://ateliers.dev/docs/development-guidelines/technical-policies/issue-classification-and-label-policy) で管理します。

このリポジトリでは方針本文やラベル定義を複製せず、正本を参照します。共通ラベル同期の仕組みを実装する場合も、ateliers-website の正本に定めるラベル定義を参照してください。
